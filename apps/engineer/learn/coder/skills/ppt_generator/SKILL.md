# PPT 生成器

## 功能

根据用户提供的文本内容，自动生成专业的PPT演示文稿。

## 使用方法

1. 阅读 REFERENCE.md 了解 API 详情
2. 查看 FORMS.md 了解表单模板
3. 使用 scripts/ 目录下的脚本生成PPT
4. 从 templates/ 选择合适模板

## 目录结构

- REFERENCE.md - API 参考文档
- FORMS.md - 表单模板说明
- scripts/ - 生成脚本
- templates/ - PPT 模板文件
